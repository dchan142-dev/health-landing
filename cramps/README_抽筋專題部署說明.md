# Health Decoder 半夜抽筋專題 · 獨立交付套件說明 (2026年9月修復版)

## 一、 套件內容
1. `cramps/index.html`：**半夜抽筋專題獨立落地頁 (100% 依循夜尿專頁底本規範)**
   - **問卷提示尊重優化 (Block B)**：修復提示文案為客觀謙和之標準語句：「提示：您填選的項目中並無任何抽筋相關徵狀（或可能填選有誤）。若您確實有抽筋症狀，請重新核對並填選符合您身體狀況的選項。」
   - **購物車階梯折扣結算 (Block H)**：
     - 當單品選購滿 HKD 1,200 自動啟動特別優惠，於已選項目結算處即時顯示綠色特惠橫幅：「✨ 已享特別優惠價 | 已慳 HKD X (X折)」，並於小計處呈現劃線原價對比。
     - 徹底隱藏「專尚配套」及「特別單件價」等後台內部名詞，前台僅呈現乾淨純粹的產品名稱、選購數量及折後金額。
   - **全站風格與架構一致**：除自測問卷、Block D/E/F 影音與文案、專案單品與套裝、見證內容因應抽筋專題而定制外，所有外觀、功能、字眼、結構、位置完全對齊夜尿專頁底本。

2. `Universal_Order_Router.gs`：全站統一訂單與自測 Webhook 路由器。

## 二、 部署步驟 (GitHub ➔ Vercel)
1. 將本壓縮包解壓後的 `cramps/index.html` 覆蓋至本地 Git 倉庫的 `cramps/` 目錄。
2. 透過 GitHub Desktop 提交變更並 Push，Vercel 將自動於 15 秒內完成部署上線。
