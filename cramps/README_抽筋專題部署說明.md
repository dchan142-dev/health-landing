# Health Decoder 半夜抽筋專題 · 獨立交付套件說明 (2026年9月修復版)

## 一、 套件內容
1. ：**半夜抽筋專題獨立落地頁 (完全對齊夜尿專頁標準)**
   - **版面極致精簡**：徹底剔除所有未授權的行銷文案、多餘說明文字、三列膠囊方塊與卡片膠囊標籤，手機版排版完全回歸純淨自然。
   - **初步自我診斷問卷 (Block B)**：
     - 去除滿分標註、評估說明、核心指標字眼與預設虛線框引導，回歸客觀自測。
     - 基本資料改為標準簡潔下拉選單（稱呼、性別、年齡區間）。
     - **零徵狀警號防護**：若受測者全選「沒有上述情況」或無任何抽筋徵狀，系統彈出警號提示（「提示：您填選的項目中並無任何抽筋相關徵狀...」），絕不錯誤預設至成因一。
   - **全域彈窗滾動修復**：
     - 採用  與  瞬間定位，徹底修復關閉 Pop-up 後頁面由頂部重新平滑滾動至底部的嚴重視覺干擾。
     - 產地欄位嚴格判斷：無產地資料之產品（如紅光按摩帶）絕不顯示「產地：」留空。
   - **選取改善方案 (Block H)**：
     - 移除頂部 200 優惠干擾橫幅，引導客人以價值與自身需求為導向選購。
     - 移除套裝標題「（享高額特別優惠折扣）」字眼。
     - 套裝內容明細移入 Pop-up B（點擊「查看套裝明細」開啟），選單維持雙行緊湊整潔。
     - 物流表單移除「配送備註」等繁冗欄位，保留收件人、電話、地址、升降機與 3 大付款方式（FPS / PayMe / AlipayHK）。
   - **用家見證與 HCMS (Block J)**：
     - 移除見證膠囊標籤與虛假煽情文字，採客觀平實的三段式描述（原本困擾、調理方案、客觀回饋）。
     - 100% 還原 HMCS 經典三問卡片（「擔心無效果？驚自己唔識處理？覺得要堅持唔易？」）。
   - **社群加入 (Block L)**：
     - 100% 還原原版：「暫時未準備好？免費加入 Duncan Chan 健康群組。」並提供 WhatsApp 與 Facebook 社群連結。

2. ：**全站統一訂單與自測 Webhook 路由器**
