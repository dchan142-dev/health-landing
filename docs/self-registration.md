# 客人自行註冊

客人從 `/intake/` 按「自行註冊」，填稱呼、電郵、密碼及確認密碼，確認資料使用用途後開始填寫。成功登記後嘗試登入；若登入連線失敗，保留電郵並引導回登入頁。已有帳號仍可使用原密碼及既有問卷。

沿用 Better Auth 及現有資料庫，對外註冊只接收 `name`、`email`、`password`、`consent`。角色等額外欄位由伺服器拒絕；新帳號固定為普通客人。新增註冊每個來源最多5次／10分鐘，計數存在資料庫，維持跨站防護。

對新註冊及重複電郵均回覆一致的成功確認，不回傳使用者ID、角色或其他可辨識差異，避免對外確認誰已登記。重複登記不更新原密碼、角色或問卷；註冊同意稽核只記錄真實新使用者。既有客人隔離、版本控制、儲存離開及提交鎖定繼續適用。

本次沒有增加寄信服務，不顯示已寄驗證信或重設信；忘記密碼仍由跟進者核實身份後重設。管理員仍可協助建戶，但一般客人不需由管理員分配密碼。

驗證涵蓋新帳號、權限欄位拒絕、同意檢查、跨站拒絕、既有帳號與密碼保留、手機表單、密碼確認、自動登入失敗後重試，以及儲存、登出與重登入續填。正式驗收只使用保留命名空間內的虛構帳號，完成後清理。
